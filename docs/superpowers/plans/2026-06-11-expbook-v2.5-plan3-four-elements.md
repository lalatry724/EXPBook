# ExpBook v2.5 — Plan 3：四元素（徽章／稱號／streak 校準／隨機彩蛋／里程碑）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Plan 1（衍生引擎）＋ Plan 2（等級系統＋面板顯示層）之上，疊加 design §3「四元素」榮譽收藏層：宣告式 24 枚徽章系統 ＋ 衍生稱號 ＋ streak 日曆週語意校準＋面板 🔥 顯示 ＋ flush 隨機彩蛋一行 ＋ 個人 PR 里程碑回顧。全部純衍生、零 EXP 入口、不誘刷。

**Architecture:** 純疊加。`scanTranscripts`/`deriveMetrics` 補三項習慣／PR 聚合（單日活躍時數、單 session 時長、單日對話數、單日 token/字、單委託最大）。新增宣告式 `ACHIEVEMENTS`（比照 `SKILL_GROUPS`）＋ 純函式 `buildBadgeContext`/`evalBadges`/`deriveTitle`/`mergeRecords`/`pickEasterEgg`。`deriveAchievements` 由「覆寫」改為「讀→合併→寫」（unlocked 只進不退、records 取 max、egg 狀態保留）。顯示層 `renderStatus` 多收一個 `ach`（徽章/稱號/PR），無則維持 Plan 2 輸出（向後相容）。`flush` 後印新解鎖徽章＋PR＋一行彩蛋（薄 AI、無 EXP）。現行 log/state/EXP 經濟/三層完全不動。

**Tech Stack:** 純 Node（零依賴，比照現有 exp.cjs）；測試 `node:test`（內建）。純函式以 inline 物件測試；掃描類用 `test/fixtures.cjs` 既有 helper（`tmpProjects`/`asstMsg`/`userMsg`）。

**Spec 來源：** `docs/superpowers/specs/2026-06-11-expbook-v2.5-design.md` §3（3.1 徽章 24 枚六類／3.2 稱號／3.3 streak 反焦慮版／3.4 隨機彩蛋／3.5 里程碑回顧）、§5.1（deriveAchievements 觸發 flush＋rebuild）。

**前置（Plan 1+2 已交付，可直接用）：**
- `deriveMetrics(scan, log)` → `derived`：`billable, totalProcessed, flows, conversations, typedChars, codeChars, codePct, activeHours, costUSD, window, quests:[{ts,reason,dungeon,billable,tier}], tierCount:{D,C,B,A,S}, elitePoints, commandLevel, slayLevel, streak:{current,longest}`。
- `scanTranscripts(root)` → `scan`：`tok, byModel, billable, totalProcessed, messages, tsList, perSession, perDay:{day→billable}, userTurns, userChars, codeChars, msgCount, fileCount, minTs, maxTs`。
- `deriveAchievements(p,opts)` 寫 `achievements.json`；`readDerived(p)` 讀回 `derived`。
- 顯示層：`renderPanelLine(state,d)`、`renderFuelDashboard(d)`、`renderStatus(state,derived=null)`、`fmtYi/fmtWan/fmtUSD/eliteLevel`。
- `computeStreak(log,todayStr)`（Plan 1，本 Plan Task 5 校準）。

**已拍板閾值（design §3.1；本 Plan 採用，鬆條件取最字面值，不重新發散）：**
- A 戰績 task 門檻 1/100/1000/10000；B 投入 指揮 10/50、殺敵 25/50。
- C 委託：首 S≥1；全階 D~S 各≥1；S 級獵人 S≥10；巨龍 單委託 > **1000 萬**（1e7）token。
- D 代價：億級 billable≥1e8；$1000／$5000；隱藏 $3000。
- E 習慣：夜術士 task 時 0–4（hour<5）；晨型 5–7（5≤hour<8）；假日 週六/日；不眠 單日活躍 >12hr；馬拉松 單 session >6hr。
- F 幽默：浴火重生＝log 序列「連 3 fail 後出現 task」；惜字如金＝任一 task 事由字元 <10；話癆＝單日對話 >50；手滑藝術家＝regress 累積 ≥3。
- 稱號＝已解鎖徽章「最高稀有度 × 最新解鎖 ts」；`config.json` `title_pin` 可覆寫（沿用既有 config 覆寫機制，STATUS.md 為輸出檔不可當輸入）。

```js
// 日曆週桶（7 天，Monday 對齊；epoch day0=Thu，+4 使 Monday 起算為整數邊界）
function weekIndex(ms) { return Math.floor((Math.floor(ms / 86400000) + 4) / 7); }

// 連勤（design §3.3 反焦慮版）：活躍日=有 task event 的日期；護符＝每進入一個新日曆週發 1 枚，
// 斷 1 天消耗 1 枚護符不算斷；current=從今日往回的連勤，longest=全期最長（PR，永久保留）。
function computeStreak(log, todayStr) {
  const days = new Set(log.filter((e) => e.kind === 'task').map((e) => e.ts.slice(0, 10)));
  if (!days.size) return { current: 0, longest: 0 };
  const dayMs = 86400000;
  const toMs = (s) => Date.parse(s + 'T00:00:00Z');
  const active = new Set([...days].map(toMs));
  // current：今日往回，遇活躍日 +1；遇空缺日有護符則消耗跳過、否則斷。每進入新週 +1 護符。
  let current = 0, cursor = toMs(todayStr), amulets = 0;
  const weeksSeen = new Set();
  while (true) {
    const wk = weekIndex(cursor);
    if (!weeksSeen.has(wk)) { weeksSeen.add(wk); amulets++; }
    if (active.has(cursor)) { current++; cursor -= dayMs; }
    else if (amulets > 0) { amulets--; cursor -= dayMs; }
    else break;
    if (current > 100000) break;
  }
  // longest：對 [min..max] 整段日期向前掃，同護符規則；斷掉時重置 run 與護符預算（新區段重新計週）。
  const sorted = [...active].sort((a, b) => a - b);
  const min = sorted[0], max = sorted[sorted.length - 1];
  let longest = 0, run = 0, amu = 0;
  let seg = new Set();
  for (let c = min; c <= max; c += dayMs) {
    const wk = weekIndex(c);
    if (!seg.has(wk)) { seg.add(wk); amu++; }
    if (active.has(c)) { run++; if (run > longest) longest = run; }
    else if (amu > 0) { amu--; }
    else { run = 0; amu = 1; seg = new Set([wk]); }   // 斷：新區段，當週重發 1 護符
  }
  return { current, longest };
}
```

```js
function pickEasterEgg(d, egg, prs, todayStr, rng = Math.random) {
  const cur = (d.streak && d.streak.current) || 0;
  if (STREAK_CELEBRATE.includes(cur)) return `🎉 連戰 ${cur} 日達成，這份堅持值得記上一筆。`;

  if (yi > (egg.lastYi || 0)) { egg.lastYi = yi; return `💥 魔力消耗跨越 ${yi} 億 token——燃料燒得轟轟烈烈。`; }
  if (prs && prs.length) return `⚡ 暴擊！刷新個人紀錄：${prs[0][0]}。`;
  if (egg.lastDay !== todayStr) { egg.lastDay = todayStr; return '🎁 每日寶箱：今天也辛苦了，繼續前進。'; }
  if (rng() < 0.03) { const i = Math.floor(rng() * RARE_LINES.length) % RARE_LINES.length; return RARE_LINES[i]; }
  return '';
}
```
