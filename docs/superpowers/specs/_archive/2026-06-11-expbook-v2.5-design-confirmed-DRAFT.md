## 0. 定調（已確認）

- **主角＝使用者**（非 AI）。等級＝使用者投入 AI 協作的累積證明。AI＝記錄系統執行引擎 + 協作夥伴。
- 「薄 AI」只約束**執行面**（AI 不讀報告進對話、只發短指令），**不代表 AI 是成長主角**。

## 3. 等級架構（四等級軸 + 雙消耗儀表板，2026-06-11 重訂）

> 原「三軸」重構：燃料軸（token）從等級錨點**降為消耗儀表板**；新增「指揮/殺敵」兩條無灌水投入軸。
> 主角＝使用者；所有等級錨「使用者真實產出」，消耗儀表板錨「資源代價」。

### 四等級軸（皆只進不退，面板「‖」左半＝榮譽等級）

| # | 名稱 | 錨定 | 曲線 | 狀態 |
|---|------|------|------|------|
| ① | 冒險者等級 | 成果量（task+200 等現有 EXP） | 線性，**現狀不動** | 確認 |
| ② | 精英冒險者 | 高價值成果（**只吃 task event**；委託規模 D1/C2/B3/A5/S8） | LV50 解鎖、另軌、門檻指數×N | 結構確認，數值表待 #017 |
| ③ | 指揮等級 | 對話次數（真打字則數，排權限 Enter/系統注入） | 線性，step 暫定 100 次/級 | 命名確認，step 待定 |
| ④ | 殺敵等級 | 打字量（不含 code 字元） | 線性，step 暫定 3 萬字/級 | 命名確認，step 待定 |

- **成果組**（①②）：你產出什麼。① 驗收制無灌水；② 後期門檻指數爬升 → 拼精英任務。
- **投入組**（③④）：你付出多少、抗灌水。③ 幾乎不可刷；④ 含貼上非 code 文字、無法剔除（見 #5 備註），標「輸入文字量」非「純手打」。
- **棄用 input_tokens 當投入錨**：它混系統/工具 token、受 context 膨脹灌水，三候選（in/對話次數/打字量）裡最不純。

### 雙消耗儀表板（負面框架·只增不升級，面板「‖」右半＝代價）

| # | 名稱 | 錨定 | 顯示 |
|---|------|------|------|
| ⑤ | 魔力消耗 | 總 token 處理量 | 50.1 億（附有效 2.04 億；其餘 ~96% 為 cache_read 翻舊帳） |
| ⑥ | 金幣消耗 | token→$（依現行定價估算） | $3,990 USD |

- **負面/消耗框架**（魔力燒掉、金幣花掉）刻意弱化炫耀感 → **強化第 4 柱「不獎勵燒 token」**：資料保留但不誘刷。
- ⑥ 不錨定錢做等級（定價會變）；定價變動只重算展示、不影響任何等級。
- 配里程碑徽章（億級燃料、破三千刀…）給成就感，但**不做升級曲線**。

### 一行式面板格式（已確認 B 分組版）

數字用**中文數量級**（億／萬字），**不用 B/M**（使用者換算緩慢：1B=10億=10萬w，太大）：
```
[等級] 冒險者18 精英0 指揮22 殺敵51   [消耗] 魔力50.1億(有效2.04億) 金幣$3,990
```
- `[等級]｜[消耗]` 左右切開：左＝會升級的榮譽（成果＋投入），右＝只增的代價。
- 單位規則：token→億（1 億=100M）、字數→萬字、錢→$。

## 4. 四元素（v1 設計，2026-06-11；全部純衍生·零 EXP·榮譽收藏。數值待最終確認 → TODO #019–023）

### 4.1 徽章系統（統一 `ACHIEVEMENTS` 一張表）
結構 `{id,名稱,稀有度,類別,描述,條件fn(state,log,transcript),隱藏?}`；稀有度 5 階 N/R/SR/UR/LR；比照現有 `SKILL_GROUPS` 宣告式。初版 ~24 枚六類（數值待 #019）：
- **A 戰績**：初試啼聲(N,首task)／百戰之身(R,100)／千錘百鍊(SR,1000)／萬卷功成(LR,10000)
- **B 投入**：見習指揮官(N,指揮Lv10)／沙場宿將(SR,指揮Lv50)／筆鋒如刃(R,殺敵Lv25)／一字千軍(SR,殺敵Lv50)
- **C 委託**：首級(N,首S)／全階通吃(R,D~S各≥1)／S級獵人(SR,累積10S)／巨龍討伐者(UR,單委託>1000萬token)
- **D 代價(負面自嘲梗)**：億級法師(R,有效1億)／燒錢如焚(SR,$1000)／揮金如土(UR,$5000)／「你知道燒了多少嗎」(SR隱藏,$3000吐槽)
- **E 習慣**：夜術士(R,0–5點task)／晨型冒險者(R,5–8點)／假日狂戰士(R,週末)／不眠騎士(SR,單日>12hr)／馬拉松(SR,單session>6hr)
- **F 隱藏/幽默**：浴火重生(R,連3fail後達成)／惜字如金(N,<10字完task)／話癆(N,單日>50對話)／手滑藝術家(N,regress累積)

### 4.2 稱號
由已解鎖徽章衍生頭銜，掛面板名旁。自動選＝**最高稀有度×最新解鎖**；STATUS.md 可手動釘選。細節 TODO #020。

### 4.3 streak（反焦慮版）
連續活躍日(當日≥1 task event)，面板 🔥N。**護符機制**：每週自動發 1 枚連戰護符，斷 1 天自動消耗、不算斷。斷掉不歸零羞辱：當前連戰歸0、最長連戰(PR)永久保留。里程碑 7/30/100/365。只看出勤不看量。寬限數值 TODO #022。

## 5. 燃料儀表板（生涯統計，不升級，人話化，已確認）

- **委託討伐記錄 D/C/B/A/S**：**task event 級 + 區間 token 歸屬**——委託規模 = 該 task 與前一筆 task 之間所有 transcript 的計費等效 token（timestamp 區間 join）。**跨多 session 自動合併成 1 件**（解決大項目分 session 死穴）。純雜事/探索 token 不形成委託、只進總統計。可回溯。可交叉地城/技能。
- **token 流量明細**：input / output / cache_write / cache_read 四分項各自累積 + 人話（input＝你新送進、output＝AI寫出、cache_write＝首次建快取、cache_read＝重複讀歷史）。
- 對話次數（role=user 非 tool_result）、打字量（user 訊息字元，標 code fence%）、使用時間（相鄰訊息 **gap<15分** 才累加）、token 總量、書本換算（計費等效×0.7字/token，10萬字=1本）、等效成本$（展示欄）。

### 計數限制備註（誠實標註，避免假精確）
- **對話次數**：= 使用者主動打字發話的則數。**權限批准的 Enter 不算**（批准不產生 user 訊息，只放行 pending 工具）。系統注入訊息用 `startsWith('<')` 粗濾排除 → 故為**近似值**，個位數誤差不當精確值。
- **打字量**：只能扣除**有 ``` fence 標記**的 code；裸貼的非 code 文字（log/JSON/路徑/引用段落）**無法剔除**。故「不含 code」**≠ 純手打**——jsonl 不記錄輸入來源，**手打 vs 複製貼上量測不出**，儀表板須標「使用者輸入文字量」而非「純手打量」。
