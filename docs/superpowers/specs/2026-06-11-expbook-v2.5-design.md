## 0. 定調

- **主角＝使用者本人**（非 AI）。等級＝使用者投入 AI 協作的累積證明。AI＝記錄系統執行引擎 ＋ 協作夥伴。
- 「薄 AI」只約束**執行面**（AI 不讀報告進對話、只發短指令），不代表 AI 是成長主角。
- 不推翻資料層（每筆工作事件照記），疊加敘事 ＋ 遊戲化機制。

## 1. 哲學相容鐵則（不可違反）

- 所有新機制（投入軸、消耗儀表板、四元素）一律 **純衍生、零 EXP 入口**，不破壞現有第 4 柱「不刷分、不獎勵掙扎」。
- 資料源：`~/.claude/projects/*/*.jsonl` 每訊息 `usage` 欄（input/output/cache_creation/cache_read）＋ `log.jsonl`。
- 度量基準：**計費等效 token = input + output + cache_creation**（排除 cache_read，佔比 ~96% 且失真、長對話自動灌數字）。
- 純疊加：現行 `log.jsonl`(SoT) / `state.json` / EXP 經濟(task+200 等) / `SKILL_GROUPS` / 三層(冒險者·地城·技能) **完全不動**。

## 2. 等級系統（四等級軸 ＋ 雙消耗儀表板）

### 2.1 四等級軸（皆只進不退；面板「‖」左半＝榮譽等級）

| # | 名稱 | 錨定 | 曲線 | 定案值 |
|---|------|------|------|--------|
| ① | 冒險者等級 | 成果量（task+200 等現有 EXP） | 線性 | **現狀不動** |
| ② | 精英冒險者 | 高價值成果（只吃 task event；委託規模 D1/C2/B3/A5/S8） | 指數累進 | **LV50 解鎖**，`cost(n)=round(500×1.2^(n-1))`，無硬上限 |
| ③ | 指揮等級 | 對話次數（真打字則數，排權限 Enter／系統注入） | 平方根 | **Lv＝⌊√(對話次數 / 4)⌋** |
| ④ | 殺敵等級 | 打字量（輸入文字量，標 code%） | 平方根 | **Lv＝⌊√(打字字元數 / 600)⌋** |

- **成果組（①②）**：你產出什麼。① 驗收制無灌水；② 後期門檻指數爬升 → 拼精英任務。
- **投入組（③④）**：你付出多少、抗灌水。③ 幾乎不可刷；④ 含貼上非 code 文字（無法剔除，見 §4.2 備註），標「輸入文字量」非「純手打」。
- 棄用 `input_tokens` 當投入錨：混系統/工具 token、受 context 膨脹灌水。

#### ② 精英曲線（#017 定案 ×1.2）

```
cost(n) = round(500 × 1.2^(n-1))   每級門檻（精英分）
精英分權重：D=1 C=2 B=3 A=5 S=8（純衍生）

累計門檻：
 Lv1  500     (累 500)
 Lv2  600     (累 1,100)
 Lv5  1,037   (累 4,318)
 Lv10 2,580   (累 16,000)
 Lv20 16,000  (累 ~100,000)
```

- 原 ×1.5 過陡已棄（實算到精英 Lv10 需 ~15 年）。×1.2：前期溫和、中後期穩爬。
- 解鎖閘：冒險者 LV50 前不計精英；面板顯示 `精英0`。
- 無硬上限。

#### ③④ 投入軸曲線（定案）

- 平方根曲線、後期邊際遞減、防爆級。
- 校準真實值：對話 2,129 次 → 指揮 **Lv23**；打字 150.2 萬字 → 殺敵 **Lv50**。

### 2.2 雙消耗儀表板（負面框架·只增不升級；面板「‖」右半＝代價）

| # | 名稱 | 錨定 | 顯示 |
|---|------|------|------|
| ⑤ | 魔力消耗 | 總 token 處理量 | 50.1 億（附有效 2.04 億；其餘 ~96% 為 cache_read 翻舊帳） |
| ⑥ | 金幣消耗 | token→$（依現行定價估算） | $3,990 USD |

- 負面/消耗框架（魔力燒掉、金幣花掉）刻意弱化炫耀感 → 強化第 4 柱「不獎勵燒 token」。資料保留但不誘刷。
- ⑥ 不錨定錢做等級（定價會變）；定價變動只重算展示、不影響任何等級。
- 配里程碑徽章（億級燃料、破三千刀…）給成就感，但**不做升級曲線**。

### 2.3 一行式面板格式（B 分組版）

數字用**中文數量級**（億／萬字），不用 B/M：
```
[等級] 冒險者18 精英0 指揮22 殺敵51   [消耗] 魔力50.1億(有效2.04億) 金幣$3,990
```
- `[等級]｜[消耗]` 左右切開：左＝會升級的榮譽（成果＋投入），右＝只增的代價。
- 單位規則：token→億（1 億=100M）、字數→萬字、錢→$。

### 2.4 命名全集

①冒險者 ②精英 ③指揮 ④殺敵 ⑤魔力消耗 ⑥金幣消耗

## 3. 四元素（全部純衍生·零 EXP·榮譽收藏；再怎麼觸發都不誘刷）

### 3.1 徽章系統（#019 定案）

統一 `ACHIEVEMENTS` 一張表。結構：
```
{ id, 名稱, 稀有度, 類別, 描述, 條件fn(state, log, transcript), 隱藏? }
```
稀有度 5 階：**N / R / SR / UR / LR**。比照現有 `SKILL_GROUPS` 宣告式。初版 24 枚六類：

| 類別 | 徽章（稀有度・條件） |
|------|---------------------|
| A 戰績 | 初試啼聲(N,首task)／百戰之身(R,100)／千錘百鍊(SR,1000)／萬卷功成(LR,10000) |
| B 投入 | 見習指揮官(N,指揮Lv10)／沙場宿將(SR,指揮Lv50)／筆鋒如刃(R,殺敵Lv25)／一字千軍(SR,殺敵Lv50) |
| C 委託 | 首級(N,首S)／全階通吃(R,D~S各≥1)／S級獵人(SR,累積10S)／巨龍討伐者(UR,單委託>1000萬token) |
| D 代價(負面自嘲) | 億級法師(R,有效1億)／燒錢如焚(SR,$1000)／揮金如土(UR,$5000)／「你知道燒了多少嗎」(SR隱藏,$3000吐槽) |
| E 習慣 | 夜術士(R,0–5點task)／晨型冒險者(R,5–8點)／假日狂戰士(R,週末)／不眠騎士(SR,單日>12hr)／馬拉松(SR,單session>6hr) |
| F 隱藏/幽默 | 浴火重生(R,連3fail後達成)／惜字如金(N,<10字完task)／話癆(N,單日>50對話)／手滑藝術家(N,regress累積) |

### 3.2 稱號（#020 定案）

- 由已解鎖徽章衍生頭銜，掛面板名旁。
- 自動選＝**最高稀有度 × 最新解鎖**。
- `STATUS.md` 可手動釘選覆寫。

### 3.3 streak（#022 定案，反焦慮版）

- 連續活躍日＝當日 ≥1 task event。面板 `🔥N`。
- **護符機制**：每週自動發 1 枚連戰護符，斷 1 天自動消耗、不算斷。
- **不歸零羞辱**：斷掉後當前連戰歸 0，最長連戰（PR）永久保留。
- 里程碑：7 / 30 / 100 / 365。只看出勤不看量。

### 3.4 隨機彩蛋（#021 定案，flush 一行·薄 AI·全無獎勵）

| 類型 | 觸發 |
|------|------|
| 寶箱 | 每日首抽，當日亮點 |
| 暴擊 | 單委託 > 個人 p90 |
| 稀有遭遇 | ~3% 隨機台詞（純 flavor，唯一隨機項） |
| 連擊慶祝 | streak 達 7 / 30 整 |
| 里程碑炸裂 | 跨億 token / 整百 task / 破 $ 關 |

條件觸發為主、隨機僅占稀有遭遇且純台詞無收益。

### 3.5 里程碑回顧（#023 定案，併入·不另開機制）

- 首次達成（＝徽章）。
- 個人 PR：**單日最高 token／單日最多字／單委託最大／最長 streak**，即時播報 ＋ 寫 `STATUS.md`。
- 月度戰報。

## 4. 燃料儀表板（生涯統計，不升級，人話化）

### 4.1 委託討伐記錄 D/C/B/A/S

- **task event 級 ＋ 區間 token 歸屬**：委託規模 = 該 task 與前一筆 task 之間所有 transcript 的計費等效 token（timestamp 區間 join）。
- **跨多 session 自動合併成 1 件**（解決大項目分 session 死穴）。
- 純雜事/探索 token 不形成委託、只進總統計。可回溯。可交叉地城/技能。

#### 委託界線（#018 定案，錨真實分位 p25/中位/p75/p90）

| 級 | 計費等效 token |
|----|----------------|
| D | < 17 萬 |
| C | 17–33 萬 |
| B | 33–76 萬 |
| A | 76–180 萬 |
| S | > 180 萬 |

#### Edge case（#025 定案）

- 中間無 task 的 token → 不形成委託、只進總統計。
- 純探索 session（整段無 task）→ 同理，只進總統計，不產委託。

### 4.2 token 流量明細（#024 定案文案）

四分項各自累積 ＋ 人話：

| 分項 | 文案 |
|------|------|
| input | 你新送進 |
| output | AI 寫出 |
| cache_write | 首次建快取 |
| cache_read | 重複讀歷史 |

### 4.3 其餘生涯統計

- 對話次數（role=user 非 tool_result）。
- 打字量（user 訊息字元，標 code fence %）。
- 使用時間（相鄰訊息 gap < 15 分才累加）。
- token 總量。
- 書本換算（**#027 定案：計費等效 × 0.7 字/token，10 萬字 = 1 本**）。
- 等效成本 $（展示欄）。

### 4.4 計數限制備註（誠實標註，避免假精確）

- **對話次數**：＝使用者主動打字發話的則數。權限批准的 Enter 不算（批准不產生 user 訊息）。系統注入訊息用 `startsWith('<')` 粗濾排除 → 為**近似值**，個位數誤差不當精確值。
- **打字量**：只能扣除有 ``` fence 標記的 code；裸貼非 code 文字（log/JSON/路徑/引用段落）無法剔除。故「不含 code」≠ 純手打——jsonl 不記錄輸入來源，手打 vs 複製貼上量測不出，須標「使用者輸入文字量」非「純手打量」。

## 5. 共用衍生引擎與存檔

### 5.1 deriveAchievements()（#026 定案）

- 新增純函式：掃 `log.jsonl` ＋ transcript（`~/.claude/projects/*/*.jsonl` 的 `usage`）→ `achievements.json`（衍生快取，可 rebuild 重算）。
- 觸發時機：**flush ＋ rebuild**。
- 增量掃描：存 `last_scanned_ts`，只掃新訊息。
- 成就解鎖永久寫入（只進不退）。
- 效能評估：列入 plan 階段實測（首次全掃 238 sessions / 26,507 訊息基準）。
- ExpBook 資料根：`~/.claude/expbook/`（可 `EXPBOOK_HOME` 覆寫）。

### 5.2 cwd 存檔（#029 定案）

- 每筆 EXP event 自動記錄當下專案資料夾真實 cwd 絕對路徑（`process.cwd()`）。
- 存 event 新欄位 `cwd`，與手動 `dungeon` tag **並存**。
- 供反推/校正地城與交叉分析。
